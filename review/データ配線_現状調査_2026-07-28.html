0. 結論(3行)

  • データの本体は「2本」ではなく実質3系統ある: ①Champions版 pokechan_data.js ②全国版 pokechan_data_all.js ③生成コンテンツページ4,900枚に焼き込まれた写し
  • SSOTのはずの reference/master_*.json は、pokechan_data.js から作られている(逆流)。だから「元データを直す」が成立していない
  • 技のキー体系が2本で完全に別(Champions=ローマ字 reitoupanchi / 全国版=英語スラグ karate-chop)。共通キー0件

4. 見つかっている実害(すべて実測)

  1. 特性の説明が別物: Champions版195件 / 全国版309件
  2. champions.in の印が10件立っていない → サーフゴーが「おうごんのからだ」を持つのに説明が出ない・エンジンも未実装(うなぎのぼり/おうごんのからだ/きゅうばん/どくのトゲ/ほうし/ほのおのたてがみ/もふもふ/よちむ/エレキメイカー/カブトアーマー)
  3. いま build_champions_view を素で回すと5件の説明文が消える(どくのトゲ/メイカー4種=本番にだけ手で足された分)
  4. 名前の切り詰め「フラエッテ(えいえん)」→ フラエッテナイトのメガシンカが到達不能(いじげんラッシュ/i18n468件と同じ型)
  5. 同じ特性の説明文が2種類(例: どくのトゲ)
  6. 生成コンテンツ4,900枚は焼き込み → SSOTを直しても再生成しない限り古いまま

5. 提案(外箱はそのまま・中身だけ作り直す)

  1. 統一版データ pokechan_data_v2.js を SSOT から生成(Champions+それ以外=最新世代/キーは英語スラグに統一/名前は正式名称)
  2. 切替は既存の仕組みを流用: いまの ?data=all と同じ要領で ?data=v2 を足すだけ。現行を壊さずに新版で遊んで確かめられる
  3. 二重公開 → 回帰(sim825/hard174/sweep919)+実機 → 安定したら旧を削除
  4. その後 ブリッジを撤去・逆流(生成物→SSOT)を断つ・コンテンツ4,900枚を再生成

やり直す範囲=master_{pokemon,moves,abilities,items}.json の4本。技の説明文は作り直さず移送(北極星で積み上げた文言を失わないため)。
