**結論: 設計(読んで・考えて・根拠つきで書く)は単独で任せてよい水準。ただし条件つき。**
1. **外部ソースは Codex に引かせない**。read-only sandbox は網に出られないので、外部URLが出たら全部「記憶」= 信用しない。ブリーフに「外部URL禁止・ローカル corpus のみ・無ければ未確認」と最初から書く(今回の教訓をブリーフ雛形に入れる)。
2. **Fable の全数照合は残す**(引用の行番号を機械で開く=10分で終わる)。今回の欠点はこれで捕まった。
3. **実装(コードを書く)はまだ試していない**=別トライアル(③解凍後・小さな縦切り1本で)。設計と実装は別の能力。
4. 「Astra」が Codex アプリ側に出ているなら model id を確認して差し替え。CLI から見える最上位は gpt-5.6-sol。
