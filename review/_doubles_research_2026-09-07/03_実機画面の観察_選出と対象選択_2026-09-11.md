# ダブルバトル 実機画面の観察 その2(Champions M-C・2026-09-11 阿部さん提供スクショ6枚)

出典: Champions ランクバトル(ダブルバトル)・M-C 期間中の実機。プレイヤー名「ナンス」vs「可靠开裆裤」。**画像はチャットに貼られたもの=ファイル保存なし**(保存するなら `review/_doubles_research_2026-09-07/screens/` に 01〜06 で)。ここは観察の文字起こし。区分は全部 **A(Champions実機)**。02 の4枚(技選択・様子を見る・コマンド根)に続く分。★**台帳#22(対象選択UI)はこの6枚目で決着**。

## 1. 選出画面(1枚目・2枚目)
- 見出し中央「ランクバトル ダブルバトル」。左上に**選出の持ち時間 01:30**(=90秒。2枚目は 00:38)。
- 左列=自分の手持ち6体: 各カード= 名前・性別・**持ち物(アイコン+名前)**・スプライト。カーソル ▶ で選ぶ。**選んだカードは黄緑に変わり、左端に選出順の番号(1〜4)が付く**(2枚目: フラエッテ=1・エルフーン=2・イダイトウ=3・ドドゲザン=4。**番号=選んだ順**であって並び順ではない=カードの上下位置は手持ち順のまま)。
- 中央の文「戦うポケモンを 4匹 選出してください」→ **4体選出(台帳#15 再確認)**。
- 右列=相手の6体: **スプライト・性別・タイプ2つ**(名前・持ち物・技は出ない)。
- 中央の凡例(M-C 新機能「つよさの表示」・右下 `Y つよさの表示ON` で切替):
  - ▲(緑)= **自分が有利な 相手のポケモン**
  - ▼(橙)= **自分が不利な 相手のポケモン**
  - !(黄)= **選出した 自分のポケモンが 不利ばかりで要注意な 相手のポケモン**
  - 印は相手カードの左に出る。**選出を進めると印が変わる**(1枚目=0/4 の時点で ▼ が5体 / 2枚目=4/4 で ▲1体・▼4体・!1体(グソクムシャ))。=**「選出した自分の4体」を基準に計算し直している**。阿部さん: シングルバトルでも M-C から同じ表示が出る。
  - ★計算式(タイプ相性だけか・技も見るか・4体の多数決か)は**出典なし** → 台帳に追加(#106)。うちの相性表(master TYPE_CHART)で「タイプ相性の多数決」を仮置きするなら**仮置きと明記**。
- 左下「0/4 選出完了」→ 4体選ぶと「4/4 選出完了」を押す → 右下が「待機中」(相手待ち)。

## 2. 対戦準備中(3枚目)
- 両者の6体を左右に並べる。自分側は**選出した4体が黄緑+番号(2,1,3,4 の順に上から=手持ち順のまま番号だけ付く)、未選出2体は紫のまま**。各カード= スプライト・タイプ2つ・性別。相手側は6体全部同じ赤・**! の印はここでも残る**(グソクムシャ)。
- 中央「00:37 対戦準備中」・両側「待機中」。

## 3. バトル画面の盤面(4枚目)
- 右上=相手の場の2体(オオニューラ ♂ 100% / グソクムシャ ♂ 100%)。**相手HP=%**。その下に相手の持ち時間 07:00 と**ボール4つ**(緑)。
- 左下=自分の場の2体(フラエッテ ♀ 171/171 / エルフーン ♀ 136/136)。**自分HP=実数/最大**。その上に**ボール4つ+薄い2つ**(=6枠のうち4つ点灯=選出数)と持ち時間 06:59。
- 場の並び(自分視点): 自分の**選出1番=フラエッテが左・2番=エルフーンが右**。相手は オオニューラが**左奥・グソクムシャが右手前**。相手HP箱の並びも オオニューラ(左)→グソクムシャ(右)=**画面上の左右とHP箱の並びは一致**。★相手の「選出1番」がどちらかは不明(相手の選出順が見えない)→ 相手枠0を自分から見て左右どちらに置くかは**未確認のまま**(台帳#107)。
- 右: `COMMAND 44`・X=様子を見る・左「+ ログを見る」。右下「たたかう」(黄緑)「ポケモン」(紫)の2ボタン(02 と同じ)。
- 持ち時間: 相手 07:00 / 自分 06:59 = **1人7分**(02 の観察 06:21 とも整合)。

## 4. 技選択(5枚目)
- 02 と同じ形: 技4行(タイプアイコン・技名・PP 現在/最大・**「こうかあり」**の相性ヒント。変化技(まもる)には無し)。`COMMAND 36`・X=様子を見る・Y=技の説明。
- 中央下に**「メガシンカ R」**のアイコン(フラエッテナイト所持=メガ可能な時だけ出る)。
- ★範囲技(マジカルシャイン=相手全体)にも「こうかあり」1つだけ=**2体分の相性をまとめて1語**(2体で相性が違う時の表示は未観察・台帳#108)。

## 5. ★対象選択画面(6枚目・台帳#22 決着)
- 技(ムーンフォース=1体選択)を選ぶと、**場の4体を 2×2 のカードで並べた選択板**が中央に出る:
  - 上段(赤帯・相手トレーナー名「可靠开裆裤」+アイコン)= 相手の2体: **左=オオニューラ・右=グソクムシャ**(HP箱と同じ並び)。各カード= スプライト・名前・HPバー・**%**・性別・上に「こうかあり」の相性ヒント。
  - 下段(青帯・自分の名前「ナンス」+アイコン)= 自分の2体: **左=フラエッテ(使用者)・右=エルフーン**。HPは実数/最大。フラエッテ(使用者)のカードにも「こうかあり」が見える(★使用者自身は 1体選択の技では選べないはず=表示だけか選べるのかは**未確認**・台帳#109)。
  - 中央に選んだ技名バナー「ムーンフォース」(タイプアイコン付)。
  - **カーソルの初期位置=オオニューラ(上段左)**=使用者フラエッテ(自分の左枠)の**同じ側**。★「正面=同じ側の枠」がうちの既定(TARGET_KINDS の default)と一致するが、初期位置が「正面」なのか「候補の先頭」なのかは1枚では決まらない(台帳#110)。
  - 右下 `B 閉じる`(=技選択へ戻る)。右上 X=様子を見る。
  - 中央に「5 / COMMAND TIME」の警告ポップアップ(コマンド残り5秒)。
- **設計への写し方**(§8.3 の target_choose): 技を押す → 2×2 の対象板(上=相手2・下=自分2、左右は盤面と同じ)→ 候補のカードだけ明るく、他は暗く → タップで決定 → 戻る=B。**候補が1つの技は板を出さず自動**(実機での「自動で飛ばす」は未観察=台帳#111。SV では対象が1つでも板が出ない技=味方全体/相手全体 は板を出さない)。
