# ダブルバトル 実機画面の観察(Champions・2026-09-07 阿部さん提供スクショ4枚)

出典: YouTube「シーズン1最終日 レート2604〜 (30秒遅延)【ポケモンチャンピオンズ/ダブルバトル】」(配信者: シャンディ・24:38 付近)。**画像はチャットに貼られたもの=ファイル保存なし**。ここは観察の文字起こし。区分は全部 **A(Champions実機)**。

## 1. 技選択画面(たたかう → 技一覧)
- 右上=相手の場の2体(リザードン 100% / エルフーン 93%)。**相手HPは % 表示**。名前の右に性別。
- 左下=自分の場の2体(ニンフィア 189/189 / スコヴィラン 58/172)。**自分HPは実数/最大**。
- 各側に **ボール4つ**(選出4体の生存表示)+ 持ち時間(自分 06:21 / 相手 06:18)。→ **選出4体を実機で確認(台帳#15 決着)**。
- 左上: 天候「にほんばれ状態 4/5」= **天候の残りターンを 残り/全体 で表示**。
- 右: 技4つ。各行=技名 / PP 現在/最大 / タイプ色アイコン / **「こうかあり」の相性ヒント**(ハイパーボイス・でんこうせっか に表示。めいそう(変化技)には無し)。
- 右上: `COMMAND 28`(コマンド残り秒)/ X=様子を見る / Y=技の説明。
- ★**対象を選ぶ画面はこの4枚に無い**(技を選んだ後の「だれに」の画面は未観察・台帳#22 は継続)。

## 2. 様子を見る(X)
- 左列=自分の手持ち: **上4体が選出(ニンフィア/スコヴィラン/ガブリアス/イダイトウ)・下2体は暗く(未選出)**。各行に HP 実数/最大・性別・アイコン。
- 中央=選んだ1体の詳細: タブ「能力 / ステータス」(L/R で切替)。タイプ2つ・技4つ(PP付)・特性・持ち物。
- 右列=**相手トレーナーの6体**: 各行にタイプアイコン(+テラス等のマーク)・性別。**場に出ている2体だけ HP% が出る**(リザードン 100% / エルフーン 100%)。残りは HP 非表示。
- 下: Y=つよさの表示OFF(ステータス表示の切替)/ B=戻る。

## 3. コマンド根(たたかう / ポケモン)
- 右下に「たたかう」「ポケモン」の2ボタンのみ(バッグ無し・にげる無し)。`COMMAND 45` から減る。
- ターン頭に中央へ「30 / COMMAND TIME」のポップアップ(4枚目)。★コマンド秒の内訳(45 と 30 の関係)は未確認 → 台帳#23 系に追記。

## 4. 設計への反映
- D5(画面)の要件に**そのまま写す**: 相手=% / 自分=実数、ボール=選出数、天候の残り/全体、相性ヒント「こうかあり」、様子を見る=3列(自分手持ち/詳細/相手6体・場の2体だけHP%)。
- 台帳#15(4体選出)= **決着(実機)**。台帳#22(対象選択UI)= **未観察のまま**(次の1枚があれば「技を選んだ直後」の画面)。
